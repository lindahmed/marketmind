# Evidence based investigation analysis

Provider analysis is opt in. In the root `.env`, set `INVESTIGATION_PROVIDER=openai`, configure `OPENAI_API_KEY`, and optionally set `INVESTIGATION_MODEL` and `INVESTIGATION_TIMEOUT_SECONDS`. The available model choices are `gpt-4o-mini` and `gpt-4o`. Restart the backend after changing configuration. See the official [Responses API reference](https://developers.openai.com/api/reference/resources/responses/methods/create) and [Structured Outputs guide](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses).

With the provider disabled (the default), the application saves a tenant scoped evidence review and does not infer causes. With the provider enabled, the shared Investigation agent sends the current workspace's question, goals, constraints, budget, metrics, rule findings and retrieved document excerpts to OpenAI. Workspace IDs, user identities and other tenants' records are not included. Provider storage is disabled for the request. The UI discloses that model analysis is enabled.

The output follows a strict schema, has bounded response tokens and a configurable timeout, and each citation is checked against the IDs gathered by Data Intelligence before it is persisted. Provider or validation failures return a sanitized HTTP 503 and do not save a misleading successful run. Investigation records store model, prompt revision, token usage and the model's evidence support estimate. The dated price schedule estimates input/output cost, accounting for cached input separately. Rates are from the official [GPT-4o mini](https://developers.openai.com/api/docs/models/gpt-4o-mini) and [GPT-4o](https://developers.openai.com/api/docs/models/gpt-4o) model pages. Actual charges may vary by account pricing or provider billing changes; update the schedule when rates change.

Audit events record document uploads/deletions, embedding failures, workspace searches and investigation attempts. Search terms and investigation questions are represented by server-keyed HMAC digests in audit metadata; document and model output text is not copied into the audit table.

This is synchronous request processing; durable jobs, LangGraph checkpoints, retry policy and per workspace cost budgets remain future Milestone 2 work. A model generated analysis is evidence based but is not a verified causal claim.
